# NeuralWeave · 联想思维引擎

> "人的大脑，由人生经历与思考方式编织而成。"

一个用于构建**个性化 AI 认知图谱**的开源框架与模板 —— 让每个人都能把自己的经历、联想与思考方式，沉淀为可运行、可扩展、可定制的 AI 大脑。

## 核心理念：联想即认知
人的大脑 = **人生经历（底色）** + **思考方式（联想规则）**。
经历不同，联想路径就不同。因此，每个人都可以拥有一个独一无二的 AI 大脑。传统知识图谱追求"正确"，而本项目追求**"让AI像人一样说话"**。

## 联想规则（核心规范）
为了让联想既自由又可读，本项目定义以下规则：
1. **主干串联**：不同的关键词（如天气、房屋、大海）作为语境主干，允许彼此互相串联。
2. **节点跳跃**：子节点允许跳跃，模拟人脑的"灵光一闪"。
3. **跨度限制**：**任意一次跳跃的跨度不得超过三个节点层级**，以确保联想有锚点，不会过度发散断裂。
